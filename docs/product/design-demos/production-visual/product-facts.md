# AI-Native 正式视觉事实基线

- 产品名称：AI-Native。
- 产品定位：面向中文 AI 初学者与产品人的渐进式 AI 知识图鉴。
- 核心承诺：帮助用户从听懂 AI 术语，进阶到判断业务场景并设计基础 AI 方案。
- 当前真实内容：12 个领域、300 个规范词条、308 条来源关系和四条已发布学习路线；默认公开注册表为 300 个词条、公开图谱为 308 条关系。
- 当前内容状态：30 个词条为 `verified`，270 个词条为 `catalogued`；目录词条不得在视觉稿中伪装为已核验深度正文。
- 当前品牌资产：只有「AI-Native」文字标识；没有 Logo、品牌色、正式字体或成熟 UI kit。
- 已批准母题：首页使用 C「关系场」，索引与搜索使用 A「索引台」，路线与长文使用 B「学习刊物」。
- 视觉禁区：通用紫色渐变、霓虹科技模板、装饰性图标、虚构数字、堆叠式 Bento 卡片和无意义节点。
- 本地事实源：`docs/superpowers/specs/2026-07-29-ai-native-design.md`、`src/data/domains.yml`、`src/data/relations.yml`、`src/generated/term-registry.json`。
- 现实参照核验：[The Pudding About](https://pudding.cool/about/) 将自身定义为数字出版物，并使用数据、视觉与叙事组织内容。
- 设计哲学核验：[Giorgia Lupi — Data Humanism](https://giorgialupi.com/data-humanism-my-manifesto-for-a-new-data-wold) 是其官方网站上的 Data Humanism 项目页面。
