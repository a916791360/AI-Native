# 来源登记：内容生产与营销文案助手

研究日期：2026-08-13。以下来源用于支持通用方法，不证明本案例已达标。

| ID          | 来源                  | 类型               | 支持的方法边界                                         | 不支持的外推                       |
| ----------- | --------------------- | ------------------ | ------------------------------------------------------ | ---------------------------------- |
| nist-ai-rmf | NIST AI RMF           | standard           | 风险分级治理、品牌事实一致性要求、切片评测与分阶段发布 | 不证明营销转化率提升或公关零违规   |
| google-pair | Google PAIR Guidebook | research-institute | 人机协作、用户控制、面向行动的不确定性与人工审核权     | 不提供内容生产团队的具体采纳率指标 |
| owasp-llm   | OWASP LLM 安全清单    | standard           | 外部素材作为不可信数据隔离、防止提示注入与越权发布     | 不替代人工合规与公关风险排查       |

## 使用规则

- 所有组织特定基线、阈值、采纳率、发布时延保持 `E0 待验证`。
- `E3 外部事实` 只用于支撑通用原则，不把外部模型效果外推为本案例结论。
- 只有「系统不得具备对外全自动发布与无审核投放权限」作为明确的发布护栏（`E2 项目事实`）。
