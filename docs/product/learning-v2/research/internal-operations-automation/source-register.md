# 来源登记：内部运营与审批自动化助手

研究日期：2026-08-13。以下来源用于支持通用方法，不证明本案例已达标。

| ID          | 来源                  | 类型               | 支持的方法边界                                           | 不支持的外推                     |
| ----------- | --------------------- | ------------------ | -------------------------------------------------------- | -------------------------------- |
| nist-ai-rmf | NIST AI RMF           | standard           | 自主性风险分级治理、数据准备度匹配、切片评测与分阶段发布 | 不证明内部流程的零差错或审计免责 |
| google-pair | Google PAIR Guidebook | research-institute | 人机协作、用户控制、面向行动的不确定性与人工接管权限     | 不提供内部运营的具体通过率指标   |
| owasp-llm   | OWASP LLM 安全清单    | standard           | 运营输入按不可信数据隔离、防止提示注入与越权执行         | 不替代企业内控与合规审计要求     |

## 使用规则

- 所有组织特定基线、阈值、自动化率、返工耗时保持 `E0 待验证`。
- `E3 外部事实` 只用于支撑通用原则，不把供应商声称的自主能力外推为本案例结论。
- 只有「系统不得具备资金、敏感权限修改等不可逆操作的全自动执行权」作为明确的发布护栏（`E2 项目事实`）。
