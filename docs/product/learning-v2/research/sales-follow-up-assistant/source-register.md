# 来源登记：销售跟进助手

研究日期：2026-08-13。以下来源用于支持通用方法，不证明本案例已达标。

| ID               | 来源                     | 类型               | 支持的方法边界                         | 不支持的外推             |
| ---------------- | ------------------------ | ------------------ | -------------------------------------- | ------------------------ |
| nist-ai-rmf      | NIST AI RMF              | standard           | 风险分级、人工监督、分级授权与事件响应 | 不证明销售场景的合规结论 |
| google-pair      | Google PAIR Guidebook    | research-institute | 用户信任、控制与「面向行动的不确定性」 | 不提供销售业务指标       |
| openai-evals     | OpenAI 评测实践          | official-doc       | 固定评测集、评分器校准与失败分类       | 不提供真实采纳率基线     |
| anthropic-agents | Anthropic Agent 工程模式 | official-doc       | 工具权限、人在回路与有界自动化         | 不证明外发授权设计正确   |
| owasp-llm        | OWASP LLM 安全清单       | standard           | 提示注入与越权输出的风险边界           | 不替代销售合规与法务审查 |

## 使用规则

- 所有组织特定基线、阈值、采纳率、误发率保持 `E0 待验证`。
- `E3 外部事实` 只用于支撑通用原则，不把供应商做法外推为本案例结果。
- 只有「任何越权外发或越权承诺必须阻断」作为明确的发布护栏（`E2 项目事实`）。
