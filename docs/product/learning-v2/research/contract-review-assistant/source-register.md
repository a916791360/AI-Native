# 来源登记：合同初审与风险标注助手

研究日期：2026-08-13。以下来源用于支持通用方法，不证明本案例已达标。

| ID          | 来源                  | 类型               | 支持的方法边界                                     | 不支持的外推                           |
| ----------- | --------------------- | ------------------ | -------------------------------------------------- | -------------------------------------- |
| nist-ai-rmf | NIST AI RMF           | standard           | 风险分级治理、数据准备度匹配、切片评测与分阶段发布 | 不证明法务合同审查的合规免责或法定效力 |
| google-pair | Google PAIR Guidebook | research-institute | 用户信任、面向行动的不确定性、证据展示与人工接管   | 不提供合同法务业务的审核采纳率基线     |
| owasp-llm   | OWASP LLM 安全清单    | standard           | 合同输入按不可信数据隔离、防止提示注入与越权动作   | 不替代专业律师与合规团队审查           |

## 使用规则

- 所有组织特定基线、阈值、漏报率、复核耗时保持 `E0 待验证`。
- `E3 外部事实` 只用于支撑通用原则，不把供应商声明外推为本案例结论。
- 只有「系统不得具备签署、定稿或合同决策权限」作为明确的发布护栏（`E2 项目事实`）。
