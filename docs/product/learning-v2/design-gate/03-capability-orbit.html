Gate 01 / AI boundary

哪些步骤真的需要概率语义能力？

团队希望把多来源反馈转成可复核的问题证据。先不要急着选模型：确定性规则、受限模型和人工分别应该负责什么？

关键事实 / E1

字段校验、精确去重、固定计数、状态和发布权限可以由确定性规则完成。

未知项 / 待真实基线

现有标签规则覆盖率、未知表达比例和各类误判成本尚未获得真实数据。

Make a decision

选择当前最合理的系统边界

选择只用于展开反馈，不提交、不计分。你可以在三条路径之间反复比较。

进入本关前

只有“希望自动分析用户反馈”的业务愿望，规则、模型、人工和发布权限尚未划界。

离开本关后 / AI 适用性判断卡

标出规则、模型与人工的初步边界，并记录暂不引入自主 Agent 及其重新评估条件。
