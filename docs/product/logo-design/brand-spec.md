# AI-Native Logo 品牌资产规格

## 方向状态

- 已选方向：方案 1「Native Matrix」。
- 确认日期：2026-07-31。
- 方向 Gate：`direction-approved.md`。
- 核心结构：8 x 8 模块网格中的 A 外轮廓与 N 负形，表达知识节点、连接关系与从内部生长的 Native 语义。

## 品牌事实

- 品牌名：AI-Native
- 品牌类型：面向中文 AI 初学者、产品经理与非算法技术人员的 AI 产品判断力学习系统。
- 核心承诺：通过 6 个能力阶段、24 道递进判断题和按需知识参考，帮助用户从理解 AI 进阶到能判断业务场景并设计可评审的 AI 产品方案。
- 核心母题：学习不是孤立背词；用户从情境与选择进入判断，再沿「前置、组成、比较、应用」四类关系补齐知识。
- 当前站点主方向：深空知识展柜。黑色暗场、暖白内容、克制的衬线标题、细规则线与关系色共同构成视觉身份。

## 已有视觉资产

- 当前标识：导航栏中的纯文字「AI-Native」，Baskerville / Songti SC 衬线回退，24px、600 字重。
- 暗场：`oklch(0.12 0.01 255)`，接近炭黑而非蓝黑。
- 主文字：`oklch(0.96 0.01 85)`，带轻微暖度的骨白。
- 关系色：前置黄、组成青、比较红、应用绿。Logo 初稿仅允许把前置黄作为极小面积校准点，不做多彩 Logo。
- 导航高度：72px；桌面端 Logo 可用高度约 28px，移动端应保持紧凑。
- 现有站点截图：用户提供的首页截图及仓库内生产视觉文件。

## 用户参考与解释边界

- 用户参考：黑底白标、几何切割、速度感、航天工业感、极高轮廓辨识度的科技公司标识集合。
- 需要迁移的属性：单色、高对比、锐利、机械精度、少笔画、远看即识别。
- 禁止复制的属性：不得复刻 X、Tesla、SpaceX、xAI 或其他现有商标的主体轮廓、字母结构与标志性扫线。
- 独创语义优先级：关系节点 / 学习路径 / A 与 N 的负形 / Native 的「从内部生长」。

## 正式使用规格

- 基础网格：8 x 8；所有边缘与转折都落在整数模块上。
- 安全空间：标志四周至少保留 1 个基础模块。
- 导航推荐高度：28px；一般 UI 最小高度：16px。
- 横向组合：图形标在左，字标在右；两者间距为约 3 个基础模块。
- 主 Logo 必须单色成立；在纯黑、骨白两种反相场景均可工作。
- 禁用渐变、发光、阴影、描边扩张、圆角化或任意改变模块比例。
- 禁止把关系四色同时填入图形标；关系色属于内容系统，不属于品牌主体。
