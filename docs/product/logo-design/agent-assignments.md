# Logo direction agent assignments

All agents must read `brand-spec.md` and `design-spec.md` in this directory before working. Do not modify production files. Use `apply_patch` for manual edits.

## logo_grid

Create `design-demos/01-native-grid.html` and screenshot it to `design-demos/01-native-grid.png` at 1600x1000. The symbol must use an 8x8 modular or pixel-derived construction reduced to a sharp one-color industrial monogram. It should encode A/N plus a connected knowledge path without looking like X. Include the required direction-board applications and verify browser rendering.

## logo_aerospace

Create `design-demos/02-vector-path.html` and screenshot it to `design-demos/02-vector-path.png` at 1600x1000. Use the user's black/white technology-company reference as a mood anchor: precise, fast, aerospace/industrial, with one memorable cut or forward path. Derive the distinctive structure from connected knowledge paths, avoid Tesla T, X, SpaceX sweep, xAI, and other trademark silhouettes. Include all required direction-board applications and verify browser rendering.

## logo_relation

Create `design-demos/03-relation-aperture.html` and screenshot it to `design-demos/03-relation-aperture.png` at 1600x1000. Use a top identity-studio conceptual reduction approach: start from "concepts are not islands" and construct the minimum geometry that can read as A, N, node, and path through positive/negative space. It must remain one-color and legible at 16px. Include all required direction-board applications and verify browser rendering.
