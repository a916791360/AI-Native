# AI-Native Logo 三方向设计规格

## 项目与目标

AI-Native 是一个渐进式中文 AI 知识网站，不是模型厂商、聊天机器人或开发者工具。Logo 的任务是为「知识图鉴 + 学习路径 + 关系图谱」建立长期识别资产，并替换当前仅用 Baskerville 排出的临时文字标识。用户希望获得类似其参考图所呈现的高级科技公司气质：黑白、高反差、少笔画、锐利、具备航天工业与未来工程感。但设计不得直接挪用任何现有公司商标的字母骨架、圆形、扫线或切口；必须从 AI-Native 自己的内容逻辑生长出来。

## 目标受众与使用场景

主要受众是中文 AI 初学者、产品经理、设计师、运营和非算法技术人员。他们通常在笔记本或手机上查术语、浏览知识图谱、进入学习路线。Logo 的第一使用场景是 72px 高的站点导航栏，目标可见高度约 24–28px；第二场景是浏览器 favicon、社交头像与分享图；第三场景是未来课程封面、研究包和演示文档。因此符号既要在 180–260px 的方向板主展示中显得精确，也要在 16px、24px、32px 下仍有清晰轮廓，不能依赖细碎线条或光效维持识别。

## 核心信息与视觉母题

必须优先表达以下语义中的至少两个：一是「A / N」或 AI-Native 的首字母身份；二是概念之间的连接、分叉与路径；三是 Native 的「从系统内部生成」而非外贴装饰；四是知识由前置、组成、比较、应用关系逐步建立。禁止使用脑形、芯片、灯泡、机器人头、无限符号、通用六边形蜂巢等 AI 行业陈词滥调。图形需要有一个能被记住的结构性动作，例如一道切口、一处负形节点、一条连续路径，而不是靠复杂度制造独特。

## 气质与形式

情感基调是冷静、权威、精密、克制，带少量向前推进的动势。高级感来自几何比例、负空间与字标间距，不来自渐变、霓虹、磨砂玻璃或三维渲染。主色使用现有站点炭黑 `#090B0E` 与暖白 `#F3F0E8`；允许用现有关系黄 `#D6AD3F` 作为方向板中的极小注记或对齐标，不得让 Logo 本体依赖彩色。图形建议采用硬边、直线、明确曲率或单一连续带，保持单色矢量可生产。

## 三方向差异要求

三案内容一致、展示尺寸一致，但设计逻辑必须不同。方向一使用「8×8 模块 / 数字原生」逻辑，将像素网格或离散单元压缩成工业化单色符号；方向二以用户提供的科技公司标识集合为现实气质锚点，强调速度切口和航天工程比例，同时从关系路径中建立独创轮廓；方向三以顶级品牌工作室的概念还原方法，从「概念不是孤岛」出发，用最少形状创造 A、N、节点与路径之间的双重阅读。三案不得只是同一个 N 换线宽，也不得出现与 X、Tesla T、SpaceX 扫线高度相似的主轮廓。

## 方向板输出

每案输出一个纯 HTML/CSS/内联 SVG 单文件和一张 1600×1000 PNG 截图，存入 `docs/product/logo-design/design-demos/`。方向板需包含：约 260px 的主符号、横向「AI-Native」组合、16/24/32px 小尺寸测试、模拟现有站点 72px 导航栏的落位、黑底与骨白底反相样例，以及一句不超过 20 个汉字的概念定位。方向板本身采用严格网格和克制注释，不添加营销文案、装饰图形或无意义数据。

## 设计推导五问

- 叙事角色：品牌方向选择板，不是成品发布海报。
- 观众距离：主要为 1m 笔记本观看，同时检验 10cm 手机与 favicon 尺寸。
- 视觉温度：冷静、精密、权威，动势只在符号结构中出现。
- 容量估算：单屏 1600×1000；主标约占左侧 45%，应用测试占右侧 55%。
- 视觉母题：知识节点不是孤岛，路径把分散概念组织成可学习的系统。

## 当前阶段边界

本轮是方向探索。三张真实方向板完成并展示后必须暂停，等待用户选择一案、混合两案或要求重做。用户确认前不得改动 `src/components/layout/SiteHeader.astro`、生产 Token、公共图片或 favicon。
